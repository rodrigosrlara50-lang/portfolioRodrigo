OTIMIZACOES APLICADAS
- Layout responsivo com breakpoints para desktop, tablet e celulares pequenos.
- Suporte a safe-area de iPhone (notch / Dynamic Island).
- Uso de 100svh para evitar cortes causados pela barra do navegador mobile.
- Tipografia fluida com clamp() para telas de 320 px ate monitores grandes.
- Galeria reorganizada para uma coluna no celular.
- Carrosseis com controles maiores e gesto horizontal por toque.
- Videos com playsinline e preload metadata.
- Video horizontal substituido por versao H.264 otimizada para web.
- Imagens em WebP e carregamento lazy fora da primeira dobra.
- Suporte a prefers-reduced-motion.
- Areas de toque com pelo menos 44 px nos controles principais.
- Cache longo de assets via vercel.json.
